## Les 3 Scheduled Tasks

### Task 1 — Assistant de productivité (durée cible : ~4:45)

**Problème :** 45 min perdues chaque matin à s'organiser entre clients, vidéos, dev, contenu.

**Scheduled Task :** Chaque jour à 7h00. Claude analyse calendrier + fichiers projets + notes → génère un plan de journée optimisé avec blocs de deep work et priorités.

**Résultat à montrer :** Le planning du matin même, avec les priorités identifiées et le temps estimé par bloc.

**Bonus "wow" :** Après la première exécution, Claude réécrit lui-même le prompt pour les exécutions suivantes. Il apprend les patterns (ex : plus de calls le lundi → créneau récup l'après-midi).

**Rétention :** Construction en x2/x4 speed avec voix off. Montrer le début de la config, couper, montrer le résultat. Pas chaque clic.

---

### Task 2 — Tri des newsletters (durée cible : ~4:00)

**Problème :** 30+ newsletters, noyées dans l'inbox avec tout le reste. Lues jamais ou 3 semaines trop tard.

**Scheduled Task :** Chaque jour à 7h15 (juste après le planning). Claude scanne l'inbox, identifie les newsletters, extrait les 3 points clés de chacune, envoie un résumé dans le reader, archive le reste.

**Résultat à montrer :** Le résumé dans le reader (5-7 newsletters condensées) + inbox avant/après.

**Insight :** "Le vrai gain c'est pas le temps. C'est que maintenant je rate plus rien. L'info pertinente me trouve."

**Rétention :** Construction PLUS COURTE que Task 1 — le viewer a compris le mécanisme /schedule. 45 sec max de config. Juste le prompt et le résultat.

---

### Task 3 — Veille concurrentielle YouTube (durée cible : ~3:45)

**Problème :** 2h/semaine à scroller 10-15 chaînes manuellement pour savoir quels sujets marchent. Toujours en retard.

**Scheduled Task :** Chaque lundi à 6h00. Claude (via Claude in Chrome) scrape 15 chaînes concurrentes, analyse titres/vues/sujets, génère un rapport + dashboard HTML avec tendances et recommandations.

**Résultat à montrer :** Le dashboard HTML complet — chaînes analysées, sujets tendances, recommandations d'angles.

**Meta-proof (le closer) :** "La vidéo que vous regardez en ce moment ? L'idée vient de ce rapport. Claude m'a montré que les Scheduled Tasks buzzaient aux US et que personne n'en parlait en français."

**Rétention :** OK d'y passer plus de temps car c'est la task teasée depuis le hook. Claude in Chrome en train de naviguer = pattern interrupt visuel naturel, différent des deux premières constructions.

## 5 mécanismes de retain

| Mécanisme | Application |
|---|---|
| **Open loops** | Hook : "la troisième..." / Transition T2 : "un truc qui me rendait dingue" / Transition T3 : "celle qui me fait gagner le plus d'argent" |
| **Pattern interrupts** | Switch face cam/screen toutes les 30 sec, zoom sur détails, avant/après inbox, dashboard HTML, Claude Chrome qui navigue |
| **"Mais d'abord"** | Task 1 : bonus prompt auto-réécrit arrive quand on pense avoir tout eu |
| **Micro-rewards** | Task 1 : planning. Task 2 : inbox clean. Task 3 : dashboard. Max 90 sec entre chaque payoff |
| **"Et ce n'est pas tout"** | Task 3 meta-proof : "cette vidéo vient de ce rapport" |

---

## Tips de rétention — tournage

**Règle des 30 secondes :** JAMAIS le même plan visuel plus de 30 sec. Alterner face cam, screen recording, face cam zoom, screen + zoom détail.

**Accélération progressive :** Task 1 = détail complet. Task 2 = prompt + résultat. Task 3 = ce qui est DIFFÉRENT (Chrome). Chaque task plus rapide que la précédente.

**Voix off sur screen accéléré :** pendant les passages config en x2/x4, voix en temps réel. Le décalage crée de l'énergie.

**Zooms stratégiques :** à chaque wow moment, zoomer sur le détail qui compte. "45 min → 0 min", compteur emails, dashboard.

**Pauses micro-dramatiques :** avant chaque résultat, 1 seconde de silence + regard caméra. "Et voilà ce que ça donne." Pause. Cut vers résultat.
