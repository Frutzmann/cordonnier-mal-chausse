Bloc 3 — Setup

3 etapes. 2 minutes.

01
Lancer la commande
claude remote-control
Depuis ton terminal, dans ton dossier projet. Ou /rc depuis une session existante.
02
Scanner le QR code
spacebar → QR
Avec l'app Claude (iOS/Android) ou ouvre l'URL dans un navigateur.
03
Connecte.
synchro active
Meme conversation. Meme contexte. Meme filesystem. Depuis ton telephone.
Bloc 5 — Comparaison

Remote Control vs Claude Code Web

Remote Control

Local → Mobile

  • Tourne sur TA machine
  • Acces a tes fichiers locaux
  • Tes MCP servers disponibles
  • Ton contexte projet complet
  • Le telephone = telecommande
Claude Code Web

Cloud Anthropic

  • Tourne sur les serveurs Anthropic
  • Sandbox Linux isolee
  • Pas d'acces a tes fichiers
  • Pas de MCP locaux
  • Autonome, rien a installer
Bloc 5 — Limites

Ce qu'il faut savoir

💳
Plan Pro ou Max requis
Pas de cle API. Pas encore dispo Team/Enterprise.
💻
Ordi allume + terminal ouvert
Si ton ordi dort ou le terminal ferme → session coupee.
📡
Connexion internet requise
~10 min sans reseau = deconnexion auto.
1️⃣
Une seule session remote
Pas de multi-session. Une session par instance.
⚠️ Ne partage JAMAIS l'URL de session ou le QR code. N'importe qui avec le lien accede a tes fichiers locaux.
